# Código de conduta

O Slyced é feito para profissionais de saúde e para quem desenvolve software para eles. Nos
issues, pull requests e demais espaços do projeto, esperamos de todos:

- respeito e cordialidade, com quem quer que seja, independentemente de experiência, profissão,
  origem, gênero, orientação, religião ou qualquer outra característica;
- críticas dirigidas às ideias e ao código, nunca às pessoas;
- cuidado com a privacidade: **nada de dados de pacientes** e nada de dados pessoais de outras
  pessoas sem permissão;
- nenhum assédio, ofensa, linguagem ou imagem sexualizada, ameaça ou provocação.

Quem mantém o projeto pode editar ou apagar comentários, issues e contribuições que
desrespeitem este código, e bloquear quem insistir nisso. Para relatar um problema de conduta
em particular, use o contato em <https://lfp.app.br>.

Inspirado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), versão 2.1.
